# One Line, Lights Out

Entry for the make.fun bounty [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e): a small Python program that writes one status update — the line an AI agent posts at the exact moment its human closes the laptop — to `/output/entry.txt`.
